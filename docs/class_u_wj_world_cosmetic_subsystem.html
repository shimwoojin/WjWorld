Detailed Description

코스메틱 인벤토리 및 로드아웃 관리 서브시스템

  • Steam Inventory 조회 (#if WITH_STEAM)
  • 인벤토리 캐시 (SteamItemDefId → ItemId 변환)
  • 로드아웃 장착/해제
  • 로컬 저장/로드 (GConfig)
