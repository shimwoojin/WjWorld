\doxysubsection{Detailed Description}
바라보는 방향의 Moving/\+\+Destructible 벽돌을 집어서 재배치하는 어빌리티
\begin{DoxyItemize}
\item GA\+\_\+\+Spawn\+Brick의 Preview + Wait\+Confirm\+Cancel 패턴 사용
\item 활성화 시:\+ 바라보는 방향에서 Moving/\+\+Destructible 벽돌 탐색
\begin{DoxyItemize}
\item 없으면 즉시 End\+Ability(b\+Was\+Cancelled=true)
\item 있으면 원래 벽돌 Destroy → 프리뷰 표시 → Wait\+Confirm\+Cancel
\end{DoxyItemize}
\item Confirm:\+ 프리뷰 위치에 같은 타입의 벽돌 새로 스폰
\item Cancel:\+ 원래 위치에 같은 타입의 벽돌 복원 
\end{DoxyItemize}
