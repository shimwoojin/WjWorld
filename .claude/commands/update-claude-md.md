# /update-claude-md - CLAUDE.md 문서 갱신

현재 세션에서 작업한 내용을 기반으로 CLAUDE.md를 갱신해줘.

## 수행할 작업

1. **현재 세션 분석**
   - 이번 대화에서 수정/추가된 파일 목록 파악
   - 새로 구현된 기능, 시스템, 클래스 식별
   - 버그 수정 및 개선사항 확인

2. **CLAUDE.md 현재 상태 확인**
   - CLAUDE.md 파일 읽기
   - 기존 구조 파악 (폴더 구조, 핵심 시스템, 구현 완료 기능 등)

3. **업데이트할 섹션 결정**
   - **폴더 구조**: 새 파일/폴더 추가 시
   - **주요 클래스 계층**: 새 클래스 추가 시
   - **핵심 시스템**: 시스템 설명 변경/추가 시
   - **데이터 흐름**: 흐름 변경 시
   - **구현 완료 기능**: 새 기능 완료 시
   - **진행 중 / 미구현**: 상태 변경 시

4. **갱신 실행**
   - 관련 섹션만 업데이트 (전체 재작성 X)
   - 기존 포맷과 스타일 유지
   - 한글 주석/설명 유지

## 갱신 원칙

- **간결하게**: 핵심 정보만 기록
- **일관성 유지**: 기존 문서 스타일 따르기
- **중복 방지**: 이미 있는 내용은 수정만
- **최신 상태 반영**: 코드와 문서 동기화

## 갱신 후

- 변경된 섹션 요약해서 사용자에게 알려주기
- 추가로 갱신할 내용이 있는지 확인
