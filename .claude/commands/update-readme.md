# /update-readme - README.md 문서 갱신

현재 세션에서 작업한 내용을 기반으로 README.md를 갱신해줘.

## 수행할 작업

1. **현재 세션 분석**
   - 이번 대화에서 수정/추가된 파일 목록 파악
   - 새로 구현된 기능, 시스템, 클래스 식별
   - 개발 진행 상황 변경 확인

2. **README.md 현재 상태 확인**
   - README.md 파일 읽기
   - 기존 구조 파악 (소스 구조, 클래스 계층, 핵심 시스템, 개발 진행 상황 등)

3. **업데이트할 섹션 결정**
   - **소스 구조**: 새 폴더/파일 추가 시
   - **주요 클래스 계층**: 새 클래스 추가 시
   - **핵심 시스템**: 시스템 설명/흐름 변경 시
   - **개발 진행 상황**: 완료/진행 중/예정 상태 변경 시

4. **갱신 실행**
   - 관련 섹션만 업데이트 (전체 재작성 X)
   - 기존 포맷과 스타일 유지
   - 한글/영문 혼용 스타일 유지

## 갱신 원칙

- **간결하게**: 핵심 정보만 기록
- **일관성 유지**: 기존 문서 스타일 따르기
- **중복 방지**: 이미 있는 내용은 수정만
- **진행 상황 반영**: 완료된 항목은 체크, 새 항목 추가

## CLAUDE.md와의 차이

- **README.md**: 외부 공개용, 프로젝트 소개 및 사용 방법 중심
- **CLAUDE.md**: 내부 개발용, 상세 구현 정보 및 데이터 흐름 중심

## 갱신 후

- 변경된 섹션 요약해서 사용자에게 알려주기
- 필요시 CLAUDE.md도 함께 갱신 여부 확인
