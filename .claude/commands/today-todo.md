# Today Todo

이전 커밋과 개발 로그를 분석해서 오늘 할 일 목록을 생성합니다.

## 사용법
```
/today-todo
```

## 실행 순서

1. **최근 커밋 분석**: 지난 7일간 커밋 확인
   ```bash
   git log --since="7 days ago" --oneline --no-merges
   ```

2. **DEVLOG.md 확인**: 최근 개발 로그에서 다음 할 일 섹션 확인
   - 경로: `DEVLOG.md`

3. **CLAUDE.md 확인**: 진행 중/미구현 섹션에서 남은 작업 파악

4. **TODO 목록 생성**: 우선순위별로 정리
   ```markdown
   # 오늘 할 일 (YYYY-MM-DD)

   ## 높은 우선순위
   - [ ] 작업 1

   ## 중간 우선순위
   - [ ] 작업 2

   ## 낮은 우선순위
   - [ ] 작업 3

   ## 참고
   - 관련 커밋이나 이슈 링크
   ```

5. **사용자에게 목록 제시**: 작업 시작 전 확인 요청

## 참고
- 커밋 메시지에서 "TODO", "FIXME", "WIP" 키워드 주목
- 이전 세션의 "다음 할 일"과 연계
- 현실적으로 하루에 완료 가능한 양으로 조절
