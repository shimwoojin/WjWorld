# Read Memo

`memo/` 폴더의 메모 파일을 읽고 요약 및 제안을 합니다.

## 사용법
```
/read-memo          # 최신 메모 읽기
/read-memo 260212   # 특정 날짜 메모 읽기
/read-memo all      # 전체 메모 요약
```

## 실행 순서

### 1. memo 폴더 파일 목록 확인
```bash
dir /b "memo\" /o-d
```
- 날짜 기준 내림차순으로 파일 목록 확인
- 파일명 형식: `YYMMDD.txt` (예: 260212.txt = 2026-02-12)

### 2. 메모 파일 읽기
- **인자 없음**: 가장 최근 날짜 파일 1개 읽기
- **날짜 지정** (예: `260212`): 해당 날짜 파일 읽기, 없으면 가장 가까운 날짜 제안
- **`all`**: 전체 파일 읽기 (최신순, 최대 10개)

### 3. 내용 분석 및 분류
읽은 메모 내용을 아래 카테고리로 분류:
- **버그/이슈**: 수정이 필요한 버그, 문제점
- **기능 요청/아이디어**: 새로운 기능, 시스템 변경 제안
- **해야 할 일**: 구체적인 작업 항목
- **방향성/설계**: 큰 그림, 아키텍처 방향

### 4. 현재 프로젝트 상태와 대조
- CLAUDE.md의 "진행 중 / 미구현" 섹션과 비교
- CLAUDE.md의 "구현 완료 기능" 섹션과 비교하여 이미 완료된 항목 표시
- 메모 내용 중 기존 시스템과 관련된 부분 연결

### 5. 요약 및 제안 출력

```markdown
# 메모 요약 (YYMMDD)

## 핵심 내용
- {메모의 주요 포인트 3줄 요약}

## 카테고리별 정리

### 버그/이슈
- {있으면 나열}

### 기능/아이디어
- {있으면 나열, 관련 기존 시스템 언급}

### 해야 할 일
- {구체적 작업 항목}

## 제안
- {우선순위 기반 "이것부터 해볼까요?" 제안}
- {구현 방향에 대한 의견 — "이런 방향은 어떨까요?"}
- {기존 시스템 활용 가능한 부분 언급}
```

## 중요 사항
- **ReadOnly**: 메모 파일을 절대 수정하지 않는다
- **제안만**: 확정된 작업이 아닌, 방향 제안과 우선순위 추천만 한다
- **컨텍스트 연결**: CLAUDE.md의 기존 시스템/구현 상태와 연결하여 실현 가능성을 함께 언급한다
- **질문 환영**: 메모 내용이 모호하면 사용자에게 명확히 질문한다
